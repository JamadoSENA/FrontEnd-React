# ProductInventory - Aplicación Frontend en React

Este es el repositorio del frontend de la aplicación **ProductInventory**, desarrollado en React y estilizado con Material UI. Aquí encontrarás los pasos necesarios para instalar, configurar y ejecutar la aplicación correctamente.

Pasos antes de ejecutar la aplicación:

1.Ejecutar los siguientes comandos en el mismo orden asignado:
- npm install
- npm install @mui/material @emotion/react @emotion/styled
- npm install --save-dev @babel/preset-env @babel/preset-react babel-jest
- npm test

2.Por ultimo, para iniciar la aplicación debera escribir el siguiente comando:
- npm start
